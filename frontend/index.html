Two Most Likely Failure Modes (Runbook D8)

1. Model Provider Timeout / Rate Limit

Symptom: LLM provider latency exceeds 15s or HTTP 429 received.

Confirmation: Circuit breaker trips to OPEN state; log records CircuitBreakerOpenException.

Recovery: Automatic fast fallback routes claims to medical-review; auto-recovers after 20s cooldown.

2. Ingestion Boundary Schema Rejection

Symptom: Hospital EMR submits malformed dates or missing mandatory diagnosis.

Confirmation: HTTP 422 returned; quarantined payload logged in quarantined_requests table.

Recovery: Inspect quarantine store via /quarantined; hospital re-submits with corrected date ranges.
